# Master Camper L3H2 — Mobile Home Design

Interactive design, layout visualization, and 3D preview for a full **Renault Master L3H2** camper van conversion.

## Specifications

- **Vehicle**: Renault Master L3H2 (Long-wheelbase, High Roof)
- **External Dimensions**: 6,198 mm (L) × 2,070 mm (W) × 2,495 mm (H)
- **Features**:
  - **Floor Plan View**: Detailed architectural layout with zones (Sleeping, Kitchen, Wet bath, Lounge, Storage, Systems).
  - **Side Elevation**: Cross-section view with vertical dimensions and headroom clearances.
  - **Interactive 3D Tour**: Built with WebGL / Three.js for real-time 3D walkthrough and interior inspection.
  - **Systems Layer**: Toggleable view for water, electrical power, gas, and heating subsystems.

## Getting Started

Open `index.html` in any modern web browser:

```bash
# Using Python's built-in web server
python3 -m http.server 8000

# Open in browser:
# http://localhost:8000
```

Or simply double-click `index.html` to open directly.
